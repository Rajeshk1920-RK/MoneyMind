# 💰 MoneyMind - Smart Personal Finance & AI Copilot

MoneyMind is a modern, 100% private personal finance tracker for Android and Web featuring automated bank SMS detection, visual cashflow analytics, savings goals, category budgets, group debt resolution, and an autonomous offline AI financial copilot.

---

## ✨ Key Features

- **📊 Unified Financial Dashboard**: Live balance overview, monthly cashflow sparklines, and category burn rates.
- **🤖 FinAI Financial Copilot**: Autonomous AI assistant with turn-anchored message scrolling, real-time expense forecasting, 50-30-20 budget optimization, and anomaly detection.
- **📱 Offline Banking SMS Engine**: Real-time parsing of Indian banking SMS (HDFC, SBI, ICICI, Axis, UPI) with zero cloud lock-in.
- **👥 SplitSmart Debt Settlement**: Multi-party group expense splitting and debt resolution matrix.
- **🎯 Visual Savings Goals**: Track targets with progress meters, compound interest projections, and automated reminders.
- **🔒 Radical Privacy**: Zero telemetry, offline-first storage, encrypted exports (CSV/PDF/JSON), and optional Supabase/PostgreSQL sync.

## 🚀 Quick Start

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or higher)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/Rajeshk1920-RK/MoneyMind.git

# 2. Navigate to project directory
cd MoneyMind

# 3. Install dependencies
npm install

# 4. Start the development server
npm run dev
```

### Production Build

```bash
npm run build
```
